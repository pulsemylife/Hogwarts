# Hogwarts Dark Messenger — V6

Android-проект на Kotlin и Jetpack Compose.

## Что добавлено в V6
- Отдельная вкладка «Учителя».
- Личные чаты с Альбусом Дамблдором, Минервой Макгонагалл, Северусом Снеггом, Рубеусом Хагридом, Филиусом Флитвиком, Помоной Спраут, Римусом Люпином и Сивиллой Трелони.
- Индивидуальные локальные сценарии ответов преподавателей.
- Учителя доступны в списке личных чатов и при создании групп.
- Система отношений теперь учитывает и учеников, и преподавателей.
- Исправлены несогласованности в сохранении отношений и обработке ответов личных/групповых чатов.

## Важно
Ответы персонажей — локальные сценарии, а не подключённый ИИ. Для свободных контекстных диалогов понадобится отдельный сервер с языковой моделью. Проект не является готовым APK и не был собран в этой среде.

## Сборка APK
1. Откройте папку проекта в Android Studio.
2. Установите Android SDK, указанный в `app/build.gradle.kts`, и JDK 17.
3. Выполните Gradle Sync.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
